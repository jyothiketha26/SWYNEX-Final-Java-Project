Student Management System

Project Description

This project is a Java-based Student Management System that uses MySQL to store and manage student details.

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- MySQL
- JDBC
- IntelliJ IDEA

Features

1. Add Student
2. View Students
3. Update Student
4. Delete Student
5. Input Validation
6. Database Connectivity

Database Details

Database: "swynex_students"

Table: "students"

How to Run

1. Install Java and MySQL.
2. Create the required database and students table.
3. Configure the MySQL connection in "DBConnection.java".
4. Add the MySQL JDBC Connector.
5. Run "Main.java".
